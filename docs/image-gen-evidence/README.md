# 画像生成の確認の証跡

[台帳](../image-gen-resources.md)の根拠になる、確認の出力を置く。`scripts/inspect-image-gen.sh` の出力を、日付つきで保存する（例: `2026-11-02-inspect.txt`）。

- 保存する前に、目で確かめる。秘密（キー・トークン・DB の接続文字列）、資料の本文、機密を含むプロンプトが入っていたら、保存しない。
  スクリプトは、秘密のパターンとプロンプトの本文を伏せるが、完全ではない。
- 画像そのもの、実行の生ログの全文は置かない。必要な行だけにする。
- ファイルを足したら、台帳の「未確認」を更新する。

**2026-11-02 時点では空。** ジョブの設定・成功した実行の生の出力は、まだ受け取っていない。
